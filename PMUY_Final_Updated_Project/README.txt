WEST BENGAL PMUY MACHINE LEARNING PROJECT — FINAL UPDATED CODE

FOLDER CONTENTS
- data/: combined PMUY + NFHS-5 dataset (Excel and CSV)
- 00_data_quality_check.py: checks missing values, duplicates and recorded zeros
- 01_data_inspection.py: dataset inspection
- 02_data_preprocessing.py: preprocessing and summary measures
- 03_trend_analysis.py: district-wise linear trend analysis
- 04_polynomial_regression.py: district-wise polynomial trend analysis
- 05_clustering.py: K-Means and Hierarchical clustering
- 06_cluster_analysis.py: cluster interpretation
- 06_nfhs_analysis.py: NFHS-5 clean-fuel analysis
- 07_model_comparison.py: UPDATED pooled regression with chronological validation
- 07_model_comparison_original.py: backup of the earlier LOOCV comparison
- 08_final_results.py: prints consolidated final results
- results/: generated CSVs, Excel files and charts

HOW TO RUN
1. Extract the ZIP.
2. Open the extracted PMUY_Final_Updated_Project folder in VS Code.
3. Open Terminal in VS Code.
4. Run: pip install -r requirements.txt
5. Run: python 00_data_quality_check.py
6. Run scripts in this order:
   python 01_data_inspection.py
   python 02_data_preprocessing.py
   python 03_trend_analysis.py
   python 04_polynomial_regression.py
   python 05_clustering.py
   python 06_cluster_analysis.py
   python 06_nfhs_analysis.py
   python 07_model_comparison.py
   python 08_final_results.py
Alternatively, double-click run_all.bat on Windows.

IMPORTANT DATA/MODELLING DECISIONS
- Six complete years (2016-17 through 2021-22) are used for regression.
- 2022-23_Apr-Feb is partial and excluded from complete-year regression validation.
- 2020-21 recorded zeros are retained; they are not changed to missing values or imputed.
- Missing NFHS-5 values remain missing and are excluded only from NFHS summaries/plots.
- The updated pooled model treats each district-year as an observation, includes district indicators, and uses chronological past-to-future validation.
- Training R2 is reported separately from test R2. Never describe training R2 as test performance.
- Negative test R2 is reported honestly; do not change data or validation splits merely to force a positive score.
- Existing clustering methods are retained.
